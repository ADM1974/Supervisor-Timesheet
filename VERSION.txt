Timesheet Approvals (Supervisor app) — VERSION 4.0  (2026-10-15)

v4.0: supervisors can SET UP CONTRACTORS from the app ("Manage contractors &
codes"). Add a contractor by name and the app auto-generates a unique access
code (unambiguous alphabet, no 0/O/1/I/L) for the green contractor app; you can
also issue a fresh code, deactivate/reactivate, and tap a code to copy it. No one
has to edit the Contractors SharePoint list by hand anymore. Any signed-in
supervisor can manage contractors; the token is still verified server-side.
  - New function: netlify/functions/contractors.js (list/add/regen/setactive/
    rename), writing the Contractors list via the shared app-only Graph creds.
    Writes Title + Code + Active (default true, so new contractors can log in).
  - Staff/supervisor passwords are Microsoft 365 and are NOT managed here.

v3.9: supervisors can AMEND a submitted week instead of rejecting it, so a wrong
timesheet no longer holds up the pay run. On an approval card, tap Amend to edit
each line's hours / work order / comment, remove a line with the cross, and add
your own note explaining the change. "Save & approve" applies the edits, deletes
any removed lines and sets the whole week to Approved in one step. Everything is
stamped on each row's Notes ("Amended & approved by <you> on <date> — <note>").
  - New function: netlify/functions/amend.js (same security re-check as decide:
    every row must still be Submitted, on one of your sites, and not your own).
  - supervisor.js gained a deleteItem helper; pending.js now returns each line's
    row id so the UI can target individual edits.
  - No new SharePoint column needed — reuses Hours / WorkOrder / Comment / Notes.

v1.1: supervisor-to-sites matching now reads the "Manager" People Picker on the
Sites list (resolves the picked person's email from 365 via the User Information
List); the "ManagerEmail" text column is now an OPTIONAL fallback, not required.


Third app in the suite (contractor + staff already exist). Supervisors sign in
with their Microsoft 365 account and approve/reject the SUBMITTED timesheets for
the sites they supervise. Reads & writes the SAME Timesheets SharePoint list.

How it decides what a supervisor sees:
  - Reads the "Sites" list and keeps rows whose ManagerEmail = the supervisor's
    email, giving their supervised sites.
  - Shows every Submitted Timesheets row for those sites, grouped one card per
    person's week (name, site, days, work orders, hours, total).
  - Approve  -> Status=Approved, ApprovedDate=now, approver email appended to Notes.
  - Amend    -> edit the lines, then Status=Approved in one step (see v3.9 above).
  - Reject   -> Status=Rejected, RejectionReason=the typed reason.
  - Server re-checks every row is Submitted AND on one of the supervisor's sites,
    so nobody can approve outside their sites.

REQUIRES one small SharePoint change:
  - Add a text column "ManagerEmail" to the Sites list and fill in each site's
    supervisor email. (Reading the Manager Person column's email via Graph is
    unreliable, so we match on this explicit text column.)

Setup (see README.md): new "Supervisor Timesheet" app registration (SPA,
single-tenant) -> client id; new GitHub repo + Netlify site (Git deploy only,
because of the 'jose' dependency); paste client id into config.js; set env vars.

Env vars (Netlify): TENANT_ID, CLIENT_ID, CLIENT_SECRET, SP_SITE_ID, LIST_ID
(app-only, reused) + SUP_CLIENT_ID (the supervisor registration's client id).

After deploy the sign-in screen reads "Version 1".
